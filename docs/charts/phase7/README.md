# Phase 7 Charts

These SVG and PNG charts summarize selected Phase 7 OLAP outputs for slides and live discussion.

| Chart | Related analysis | Purpose |
| --- | --- | --- |
| `01_night_trips_by_borough_daytype.svg` / `.png` | Analysis 1 | Shows geographic concentration of night demand by weekday/weekend. |
| `02_holiday_night_share.svg` / `.png` | Analysis 6 | Shows how calendar-event context changes the relative night-trip share. |
| `03_top_night_nta_corridors.svg` / `.png` | Analysis 5 | Shows the strongest night origin-destination NTA corridors. |
| `04_station_net_flow_imbalance.svg` / `.png` | Analysis 5 companion | Shows NTA-level night net-flow for the same areas appearing in the top corridor chart. |

The charts are based on the January 2024 development warehouse baseline documented in `docs/phase7_olap_analysis.md`.

Use SVG files when the presentation tool supports vector graphics. Use PNG files when the tool imports raster images more reliably.
